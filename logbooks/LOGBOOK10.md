Editamos o arquivo "/etc/hosts" para incluir o *web server*:

![](images/guiao10/hostsetup.png)

Para as tarefas, teremos de usar os seguintes comandos:

* *lstcmd*: lista todos os arquivos no diretório "Labhome"

Exemplo de sintaxe:

![](images/guiao10/lstcmdex.png)

O pedido inclui um nome, uid e o comando.

O campo *myname* deverá ser substituído com o nome real de um dos elementos do grupo, e o comando deverá ser definido a 1.

* *download*: o servidor retornará os conteúdos do arquivo especificado do diretório "LabHome".

Exemplo de sintaxe:

![](images/guiao10/dwnldcmdex.png)

O pedido inclui o nome do arquivo e requer um endereço MAC válido para que o comando seja executado.
